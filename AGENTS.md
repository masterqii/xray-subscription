# Maintenance

This is a standalone public Xray deployment and static subscription project.
Do not add dashboards, user registration, traffic accounting, or personal deployment records.
Never commit real settings, private keys, client UUIDs, subscription tokens or URLs.
Use documentation IP ranges and example.com in fixtures. Generated files belong outside Git.
Test pure renderers and provisioning failure paths before publishing changes.
