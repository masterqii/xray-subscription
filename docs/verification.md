# 验证边界

本仓库针对全新服务器提供安装器，未在朋友的真实 VPS 上部署；不代表已验收朋友的 DNS、证书、客户端版本或网络线路。

离线测试覆盖四种格式、IPv4/IPv6、特殊字符、安全输入校验和多节点；测试参数全部是虚构数据。支持通过 `XRAY_TEST_BIN` 指定本机 Xray 二进制，对生成的服务端配置做实际语法检查。

自行部署后依次确认：

1. 服务器 DNS、云防火墙、系统防火墙与监听端口一致。
2. `xray run -test`、`nginx -t` 通过，服务 active。
3. 订阅 HTTPS 证书匹配域名，无跳过证书校验；四个 URL 输出非空。
4. 对应客户端成功导入，连接节点，实际出口 IP 等于自己的 VPS。
5. 经代理访问目标 HTTPS 服务；不要用自动故障转移到其他节点后的成功作为验收。
6. `certbot renew --dry-run` 成功，续期 timer 已启用。

本机使用 curl 验证显式 SOCKS 代理的例子（端口以客户端为准）：

```bash
curl --proxy socks5h://127.0.0.1:7890 https://www.cloudflare.com/cdn-cgi/trace
curl --proxy socks5h://127.0.0.1:7890 -I https://www.google.com/
```

不要把服务器上直连请求的成功当作客户端握手成功。手机和路由器要分别验收，路由器保留原有直连规则。服务端日志可能含网络元数据，对外分享前脱敏。
